# drillscope

Drill identifiers and scope tokens for idempotent workflows.

**Site:** https://theworker02.github.io/drillscope/

## Install / run

```bash
git clone https://github.com/theworker02/drillscope.git
cd drillscope
node src/cli.js
node --test
```
